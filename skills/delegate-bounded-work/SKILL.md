# Delegate bounded work

Delegate only when parallel work reduces total effort and the subtasks can be reviewed independently.

1. Check that delegation is available and allowed by the user's request and applicable instructions. If not, continue without delegating.
2. Split the task by independent output or file ownership. Avoid concurrent edits to shared files. Keep dependent work in order.
3. Give each worker the goal, source material, exact boundary, output format, evidence standard, and side-effect limits. Include only context needed for that assignment.
4. Match the worker's capability to the task. Use a lower-cost suitable model for bounded work when available, and reserve deeper review for complex or sensitive decisions.
5. Ask workers to report findings, sources, files changed, validation performed, and unresolved questions. Reviewers should be read-only unless editing is explicitly assigned.
6. Integrate the work yourself. Inspect the actual artifacts, resolve conflicts, verify claims, and re-check any file changed after review.
7. Record incomplete or nonresponsive assignments as incomplete. Do not imply approval or consensus without a review of the final result.

Keep the lead agent accountable for scope, permissions, integration, and the final report. Delegation does not grant permission for external actions.
